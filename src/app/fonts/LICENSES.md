# Bundled fonts

Self-hosted so builds never depend on fetching from Google Fonts. Files come from Fontsource 5.3.0 packages
(unmodified WOFF2 subsets of the Google Fonts releases).

| File | Family | Licence |
|---|---|---|
| `plus-jakarta-sans-latin-wght-normal.woff2` | Plus Jakarta Sans (variable 200–800) | SIL Open Font License 1.1 |
| `dm-sans-latin-wght-normal.woff2` | DM Sans (variable 100–1000) | SIL Open Font License 1.1 |
| `noto-sans-devanagari-devanagari-wght-normal.woff2` | Noto Sans Devanagari (variable 100–900, Devanagari subset; Latin falls back to DM Sans) | SIL Open Font License 1.1 |
| `permanent-marker-latin-400-normal.woff2` | Permanent Marker 400 | Apache License 2.0 |
